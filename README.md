# 🎛️ SYNTH-01: Tactile Kinetic Instrument

> **Awwwards-Tier Interactive Scrollytelling Showcase & Hardware Landing Page**  
> Engineered & Designed by **Abiyyu Shiddiq As'ad (KaptenBiu)**  
> Built with React 19, Tailwind CSS v4, GSAP ScrollTrigger, Lenis Smooth Scroll, and native Web Audio API.

---

## ⚡ The Narrative (5 Cinematic Acts)

1. **Act 1: The Reveal (Hero)** — Complete instrument floating in obsidian matte space (`#0A0B0E`) with glassmorphic telemetry HUD and ambient hum audio toggle.
2. **Act 2: The Exploded Parallax View** — Scroll-driven mechanical deconstruction: top aluminum chassis ascends, illuminated PCB core remains centered, bottom chassis descends in 3D parallax.
3. **Act 3: The Pinned Presentation Deck** — Viewport locks (`pin: true`) while scroll scrub cycles through 3 engineering slide cards: Dual Analog Filter, Tactile Encoders, and 16-Step Kinetic Sequencer.
4. **Act 4: The Interactive Sound Lab** — Fully playable, zero-dependency Web Audio API synthesizer widget with 4 trigger pads (`C3`, `E3`, `G3`, `B3` / keys `A`, `S`, `D`, `F`), dynamic Cutoff slider, waveform selector, and live canvas oscilloscope.
5. **Act 5: Technical Telemetry & Reserve Batch 01** — Monospaced specification matrix, *Signal Orange* laser-glow reservation CTA with instant serial generation, and agency footer.
